# diagrams

## hospital_erd.drawio

Diagrama ERD completo do banco, no formato nativo do [draw.io](https://app.diagrams.net).

### Como abrir

1. Acesse [app.diagrams.net](https://app.diagrams.net)
2. *File → Open from → Device*
3. Selecione `hospital_erd.drawio`

### Conteúdo

- **15 entidades** com todos os campos listados
- **24 relacionamentos** com notação **crow's foot**
- Cardinalidades em cada extremidade: `||`, `o{`, `o|`
- Campos PK com fundo amarelo (🔑) e campos FK com fundo azul (⚙)

### Código de cores

| Cor | Grupo |
|---|---|
| 🟣 Roxo | Pessoas (Paciente, Médico, Funcionário) |
| 🟢 Verde | Endereço do Paciente |
| 🟠 Laranja | Estrutura física (Departamento, Quarto) |
| 🔵 Azul | Eventos clínicos e farmácia |
| 🟡 Amarelo | Financeiro (Pagamento) |
| 🔴 Vermelho | Obituário |
