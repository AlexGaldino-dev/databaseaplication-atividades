# docs

## descricao_banco_hospital.docx

Documento Word com a descrição técnica e estrutural completa do banco de dados.

### Conteúdo (7 seções)

1. **Visão Geral** — tabela resumo com todas as métricas do banco
2. **Normalização** — justificativa das 3 formas normais aplicadas com exemplos concretos
3. **Estrutura das Tabelas** — as 15 tabelas detalhadas com campo, tipo de dado e descrição
4. **Relacionamentos e Cardinalidades** — tabela com os 24 vínculos, tipo e notação crow's foot
5. **Dados Populados** — distribuição de tipos sanguíneos, especialidades, óbitos e pagamentos
6. **Recursos Técnicos** — colunas geradas, ENUM, chave composta, regras ON DELETE/UPDATE
7. **Arquivos Gerados** — inventário completo dos arquivos do projeto
